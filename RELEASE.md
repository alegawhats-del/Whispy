# Whispy — как выпускать версии и обновления

## Разовая настройка (один раз)
1. На GitHub создай **публичный** репозиторий `whispy` (приватный не подойдёт: программа
   читает `version.json` и качает установщик без логина).
2. В claude.ai → Settings → Connectors подключи GitHub и дай доступ к репозиторию.
3. Скажи Claude свой GitHub-логин — он пропишет его в `UPDATE_URL` (app.py) и в `version.json`
   и запушит исходники в репозиторий.
4. Поставь на свой ПК Inno Setup 6: https://jrsoftware.org/isdl.php

## Где что лежит у пользователя
- Установленная версия: программа в `Program Files\Whispy`, транскрипты в `Документы\Whispy`,
  модели и настройки в `%LOCALAPPDATA%\Whispy`.
- Портативная (`Whispy.exe` одним файлом): всё рядом с exe.

## Выпуск новой версии — по шагам
1. Claude отдаёт новый `app.py` с увеличенным `APP_VERSION` (например `2.3.0`) и пушит
   исходники в репозиторий. `version.json` пока **не трогаем**.
2. Ты: `build.bat` → `build-installer.bat` → получаешь `installer_out\Whispy-Setup-2.3.0.exe`.
   Нужен портативный — ещё `build-onefile.bat` → `dist\Whispy.exe`.
3. На GitHub: Releases → Draft a new release → tag `v2.3.0` → перетащи
   `Whispy-Setup-2.3.0.exe` (и `Whispy.exe`) → Publish.
4. Напиши Claude «залил 2.3.0» — он обновит `version.json` (версия, ссылки, что нового) и запушит.
   Порядок важен: сначала файлы в Release, потом `version.json`, иначе у людей будет 404.
5. У пользователей при следующем запуске появится окно «Есть обновление» → «Обновить».
   Установщик ставится тихо и перезапускает программу.

## Проверка, что обновления работают
- Помощь → Проверить обновления. Если версия в `version.json` выше — предложит обновиться.
- Быстрый тест: временно поставь в `version.json` версию `9.9.9` — должно предложить.

## Если что-то не так
- «Не удалось проверить обновление» — нет интернета или `UPDATE_URL` указывает не туда.
  Он должен вести на raw-файл: `https://raw.githubusercontent.com/alegawhats-del/Whispy/main/version.json`.
- «Файл подозрительно мал» — ссылка в `version.json` битая (Release не опубликован или имя файла другое).
- SmartScreen при первой установке — «Подробнее → Выполнить в любом случае»; обновления через тихий
  установщик этот экран не показывают, т.к. запускаются из уже установленной программы.
