# Whispy — YouTube-ссылка в текст + главное через ИИ

Вставила ссылку → «Получить текст» → `.txt` с таймкодами `[00:12:30] текст`.
Потом одной кнопкой — тезисы, таблица, блок-схема, презентация или инфографика через Claude.
Транскрипция полностью локальная и бесплатная.

## Как работает
1. Сначала берёт готовые субтитры YouTube (секунды, без нагрузки на ПК).
2. Если субтитров нет — качает только аудио (yt-dlp) и распознаёт через faster-whisper.
3. Файл сохраняется в папку `Транскрипты` рядом с программой.
4. Блок «ИИ-ассистент»: выбираешь формат → «Скопировать промпт + текст» → вставляешь в Claude
   (кнопка «Открыть Claude» открывает чат). Готовый промпт сам просит нужный формат.
5. Хочешь автоматом — нажми ⚙, вставь API-ключ Anthropic, и кнопка «Сделать через API»
   сохранит результат в «Транскрипты» (платно, по тарифу Anthropic).

## Сборка
- Обычная: `build.bat` → `dist\Whispy\`
- Один exe: `build-onefile.bat` → `dist\Whispy.exe`
- Установщик: `build-installer.bat` → `installer_out\Whispy-Setup-x.y.z.exe` (нужен Inno Setup 6)
- Обновления: Помощь → Проверить обновления, плюс автопроверка при старте. Как выпускать — в `RELEASE.md`.

## Установка и сборка
1. Python 3.10–3.12 с python.org (галочка **Add to PATH**).
2. Двойной клик по `build.bat`. Спросит про видеокарту NVIDIA и соберёт `dist\Whispy\Whispy.exe`.
3. Для запуска без сборки — `run.bat`.

## В окне
- **Ctrl+V / Ctrl+C / Ctrl+A** работают в любой раскладке, плюс кнопка «Вставить».
- **Язык**: русский (по умолчанию), украинский, английский, авто.
- **Модель**: `small` (быстро) · `medium` (баланс) · `large-v3` (максимум качества, нужна NVIDIA).
- **Устройство**: авто / NVIDIA / CPU.
- **Тема**: тёмная и светлая, кнопка в карточке ссылки. Все настройки запоминаются в `settings.json`.

Модель скачивается один раз в папку `models` (medium ≈ 1.5 ГБ, large-v3 ≈ 3 ГБ), дальше офлайн.

## Если что-то не так
- **«YouTube попросил подтвердить, что вы не бот»** или видео не качается — обнови загрузчик:
  `venv\Scripts\pip install -U yt-dlp` и пересобери `build.bat`.
- **Медленно на процессоре** — выбери `small`, или поставь NVIDIA-библиотеки (`requirements-gpu.txt`).
- Используй только для личных нужд: скачивание нарушает правила YouTube.
